# BancABC IntelliBank

Analytics and decision-support platform for the BancABC Universities Hackathon 2026.

## Goals
- Identify customers at risk of churn.
- Identify high-value customer segments.
- Surface cross-selling opportunities.
- Present actionable transaction insights in a business intelligence dashboard.

## Status
Initial project setup. Demonstration data must be synthetic and clearly labelled until the official hackathon dataset is supplied. No real BancABC customer data is included.

## Planned stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS, Recharts.
- Backend: Python, FastAPI, Pandas, scikit-learn.
- Database: PostgreSQL (planned).

## Next steps
1. Confirm the official dataset schema and competition rules.
2. Build data validation and preprocessing.
3. Implement churn modelling and customer segmentation.
4. Add cross-sell recommendations and dashboard views.

## Security
Do not commit customer personal information, credentials, API keys, or confidential data.
